# DeutschLern 🇩🇪 ⇄ 🌍 (DE ⇄ RU, EN, UK, AR, FA, RO)

Нативное Android-приложение для изучающих немецкий язык (уровень B2). Приложение сочетает точный контекстный переводчик на базе современных нейросетевых моделей со структурированным личным словарём, автоматической фиксацией слов по учебным урокам и системой интервального повторения **SM-2** с 3D флеш-карточками.

---

## 📱 Основные возможности

1. **Мультипровайдерный мультиязычный переводчик**:
   - **Многоязычные пары с немецким ядром**:
     - Немецкий ⇄ **Русский** (RU, по умолчанию)
     - Немецкий ⇄ **Английский** (EN)
     - Немецкий ⇄ **Украинский** (UK)
     - Немецкий ⇄ **Арабский** (AR, с полной поддержкой RTL справа налево)
     - Немецкий ⇄ **Дари** (FA / Афганский фарси, с поддержкой RTL справа налево)
     - Немецкий ⇄ **Румынский** (RO)
     - Мгновенный выпадающий селектор языка-партнера прямо на плашке направлений перевода.
   - **Гибкая архитектура провайдеров (BYOK — Bring Your Own Key)**:
     - Поддержка провайдеров с бесплатными тарифами: **Google Gemini**, **Groq**, **Mistral AI**, **Cerebras**, **OpenRouter**, **DeepL** (TEXT), **ML Kit** (офлайн TEXT) и **Custom HTTPS OpenAI-compatible**.
     - Выбор активного провайдера и модели отдельно для режима **СЛОВ** (WORD) и **ТЕКСТОВ** (TEXT).
     - Динамическая загрузка списка моделей напрямую из API (`GET /models`).
     - Автопереключение (Fallback) при ошибках (404, 429 с `Retry-After`, 5xx, таймаут, невалидный JSON), исключая ошибку 401/403 (неверный ключ).
     - Пошаговый даунгрейд JSON-режима для моделей: `json_schema` ➔ `json_object` ➔ `plain_text` с сохранением выученного режима в DataStore.
     - Клиентский rate-limiter с учетом заголовков `Retry-After`.
   - **Автоматический выбор режима ввода**:
     - **WORD режим** (1–3 токена без пунктуации): словарная карточка (артикль, часть речи, формы глаголов `Präsens`, `Präteritum`, `Partizip II`, управление, полисемия до 5 значений с B2-примерами, синонимы, устойчивые выражения).
     - **TEXT режим** (более 3 слов): связный перевод длинных текстов с сохранением абзацев (до 5000 символов) с возможностью копирования и шеринга. При отсутствии сети или выборе ML Kit — полностью офлайн-перевод.
   - **Поле контекста**: опциональное поле «Контекст (предложение)» — нейросеть автоматически определяет точное контекстное значение и отмечает его бейджем `best_match`.
   - **Умное кэширование**: двухуровневый кэш Room (точный по провайдеру/модели + кросс-модельный семантический кэш), кнопка «Обновить другой моделью» для мгновенного обхода кэша.
   - **Автосохранение**: успешные переводы слов автоматически заносятся в активный урок Room DB.
   - **Озвучка (TTS)**: произношение немецких лемм и примеров через Android Text-to-Speech с обработкой отсутствия языкового пакета.

2. **Переключение языка интерфейса (Локализация & RTL)**:
   - **8 языковых профилей**:
     - 🇷🇺 **Русский** (по умолчанию)
     - 🇬🇧 **English** (Английский)
     - 🇩🇪 **Deutsch** (Немецкий)
     - 🇺🇦 **Українська** (Украинский)
     - 🇸🇦 **العربية** (Арабский, с полной поддержкой RTL)
     - 🇦🇫 **دری** (Дари, с полной поддержкой RTL)
     - 🇷🇴 **Română** (Румынский)
     - ⚙️ **Системный** (System default)
   - **Мгновенное переключение на лету**: выбор языка в меню «Настройки» (`SettingsScreen`) мгновенно обновляет все строковые ресурсы через Compose `LocalConfiguration` и `LocalContext` без мерцания или перезапуска приложения.
   - **Поддержка RTL-макета**: при выборе арабского языка или дари весь макет зеркалируется справа налево (`LocalLayoutDirection provides LayoutDirection.Rtl`).
   - **Интеграция с Android 13+ Per-App Language Preferences**: поддержка `LocaleManager.applicationLocales` и системного `res/xml/locales_config.xml`.
   - **Персистентность**: выбор пользователя надёжно сохраняется в `SettingsRepository` (DataStore Preferences).

3. **Словарь уроков («Слова»)**:
   - Группировка слов по сессиям/урокам («Урок, 4 окт») со sticky headers.
   - Возможность ручного создания урока («Новый урок»).
   - Быстрый поиск: нечувствителен к регистру и диграфам умлаутов (`"uber"` находит `"über"`, поиск по переводу и примерам).
   - Сегментированные фильтры: **«Все»**, **«Новые»**, **«Учу»**, **«Выучено»**.
   - Сортировка: по дате добавления, по алфавиту, по числу повторных переводов.
   - Детальный Bottom Sheet с полной словарной карточкой и возможностью выбора «Моего значения».
   - Удаление свайпом (Swipe-to-Dismiss) с всплывающим Snackbar «Отменить» (Undo).
   - Экспорт в **Anki (CSV)** по стандарту RFC 4180 через системный Android Sharesheet.

4. **Интервальное повторение («Повторение»)**:
   - Алгоритм **SM-2**: оценки **«Снова»**, **«Трудно»**, **«Хорошо»**, **«Легко»**.
   - Плавный 3D-переворот карточки ($\le 220$ мс) с аппаратным анти-зеркалированием.
   - Приоритет проблемных слов в очереди (высокий `timesTranslated`, низкий `easeFactor`).
   - Переключатель направления карточек: `DE → RU` / `RU → DE`.
   - Режим «Слова последнего урока» (повторение свежего материала вне зависимости от срока наступления повторения).
   - Логика «Снова» (`AGAIN`): моментальный возврат карточки в конец текущей очереди для закрепления.

5. **Проверка немецкого текста («Проверка»)**:
   - **Принцип минимальной правки (Minimal-Edit)**: ИИ исправляет только реальные ошибки (орфография, капитализация существительных, `ß`/`ss`, грамматика, падежи, управление, порядок слов, пунктуация), строго сохраняя авторский стиль, структуру абзацев и исходную лексику.
   - **Защита от переписывания (Over-Edit Guard)**:
     - Инварианты: числа, даты, URL, email и имена собственные защищены от изменений.
     - Лимит лексических правок $\le 30\%$ (регистр и пунктуация не штрафуются).
     - Автоматический однократный строгий повтор при попытке перефразирования.
   - **Интерактивный Diff**:
     - Удалённый текст зачёркнут, исправления выделены цветом.
     - Возможность принимать или отклонять правки по отдельности («Принять все» / «Отклонить все»).
     - Добавление исправленных незнакомых слов в личный словарь пользователя в один клик.
   - **История проверок**: локальное сохранение прошлых проверок со свайпом на удаление и очисткой.

6. **Ввод текста с фото (Photo-to-Text OCR)**:
   - **100% On-Device**: распознавание выполняется полностью локально на устройстве без отправки фотографий в сеть и без сохранения их на диск.
   - **Google ML Kit Document Scanner**: автоматический поиск границ листа, исправление перспективы, удаление теней и повышение контраста.
   - **Альтернативные источники**: стандартная камера устройства (`FileProvider`) и системный Photo Picker (галерея).
   - **Умная постобработка немецкого текста (`OcrPostProcessor`)**:
     - Автоматическая дегифенация переносов строк (`Spra-` + `che` $\rightarrow$ `Sprache`).
     - Сохранение составных слов через дефис (`Baden-Württemberg`, `U-Bahn`).
     - Сохранение абзацев и умлаутов (`ä, ö, ü, ß`).
   - **Обязательный экран предпросмотра**: редактирование текста перед вставкой, дисклеймер о локальности, мгновенная очистка временных файлов JPEG.

7. **Системная интеграция Android**:
   - `ACTION_PROCESS_TEXT`: выделение текста в любом браузере или приложении показывает пункт **«DeutschLern – перевести»**, открывая экран перевода с мгновенным результатом.
   - `ACTION_SEND`: возможность поделиться текстом из любого приложения в DeutschLern.

## 🛠 Технологический стек

- **Язык**: Kotlin 2.0 (Kotlin DSL `build.gradle.kts`, Version Catalog `libs.versions.toml`).
- **Минимальный SDK**: Android 8.0 (API 26).
- **Целевой SDK**: Android 15 (API 35).
- **UI**: Jetpack Compose + Material 3 (Strict Minimalism: near-white `#FAFAFA`, dark `#0E0E0E`, accent `#3B5BDB`, 1dp hairline dividers, плоский стиль, 5 вкладок навигации с поддержкой 200% font scale).
- **Архитектура**: MVVM + Unidirectional Data Flow (`UiState`, `UiEvent`), Kotlin Coroutines + Flow (`collectAsStateWithLifecycle`).
- **DI**: Hilt (с KSP кодогенерацией).
- **База данных**: Room (v6, таблицы `sessions`, `words`, `session_words`, `review_states`, `text_translations`, `cache`, `text_checks`, non-destructive migrations).
- **Безопасность**: Защищённое хранилище API-ключей `SecureKeyStorage` на базе Android Keystore (AES-256-GCM с fallback StrongBox ➔ TEE, автоматическая очистка при компрометации/утере ключа Keystore, маскировка авторизационных заголовков в логах).
- **Сетевой слой**: OkHttp + Retrofit + `kotlinx.serialization`.
- **Офлайн-перевод и OCR**: Google ML Kit Translate (DE ⇄ RU) + ML Kit Document Scanner & Bundled Latin Text Recognition.
- **Тесты**: 272 passing unit tests (JUnit, MockK, Turbine, Room in-memory).
- **Сборка и оптимизация**: R8/ProGuard rules для DTO, Room, ML Kit и криптографии, чистая сборка `assembleRelease`.

## ⚙️ Настройка и управление ключами (BYOK)

Все API-ключи настраиваются **напрямую в приложении** через экран «Настройки» (иконка шестерёнки в верхней панели вкладки «Перевод»):
1. **Google Gemini**: можно использовать бесплатный ключ из [Google AI Studio](https://aistudio.google.com/app/apikey) (в debug-сборках также автоматически подхватывается `GEMINI_API_KEY` из `local.properties`).
2. **Groq**: бесплатный ключ с поддержкой LPU из [Groq Console](https://console.groq.com/keys).
3. **Mistral AI**: бесплатный ключ из [Mistral Console](https://console.mistral.ai/).
4. **Cerebras**: ключ из [Cerebras Cloud](https://cloud.cerebras.ai/).
5. **OpenRouter**: агрегатор моделей (по умолчанию отображаются бесплатные модели с суффиксом `:free`).
6. **DeepL**: ключ Free (`:fx`) или Pro для качественного перевода связных текстов. В настройках доступен индикатор расхода квоты символов.
7. **Пользовательский OpenAI-провайдер**: поддержка любого HTTPS эндпоинта и модели.

> 🔒 **Безопасность и конфиденциальность**:
> - API-ключи никогда не сохраняются в открытом виде и шифруются аппаратным чипом устройства (Android Keystore).
> - Бесплатные тарифы некоторых LLM-провайдеров могут использовать запросы для обучения моделей. Не рекомендуется передавать строго конфиденциальные персональные данные на публичных бесплатных тарифах.

## 🧪 Запуск тестов и сборка APK

### Запуск unit-тестов
Проект покрыт исчерпывающим набором из **173 unit-тестов** (алгоритм SM-2, переключение и персистентность языка интерфейса, парсинг JSON, мультиязычные детекторы, нормализатор текста, поиск с умлаутами, репозитории, ViewModels, экспорт CSV):

```powershell
$env:PATH = ($env:PATH -split ';' | Where-Object { $_ -notmatch 'Tailscale' }) -join ';'
.\gradlew.bat testDebugUnitTest
```

### Сборка Debug APK
```powershell
$env:PATH = ($env:PATH -split ';' | Where-Object { $_ -notmatch 'Tailscale' }) -join ';'
.\gradlew.bat assembleDebug
```
Собранный APK доступен по пути:
`app/build/outputs/apk/debug/app-debug.apk`

### Установка на устройство через ADB
```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n app.deutschlern/.MainActivity
```

## 📦 Экспорт в Anki (CSV)

1. Откройте вкладку **«Слова»**.
2. В правом верхнем углу нажмите иконку экспорта (поделиться).
3. Системное окно Android Sharesheet предложит отправить сгенерированный файл `deutschlern_anki.csv` (в Telegram, на почту, в Google Drive или напрямую открыть в AnkiDroid).
4. Файл полностью совместим с форматом импорта карт Anki:
   - Лицевая сторона: Немецкое слово с артиклем (например, `der Hund`).
   - Оборотная сторона: Русский перевод, пояснение и натуральный B2 пример предложения на немецком с переводом.
